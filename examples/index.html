ui-annotator 示例

全部可以用 file:// 双击直接打开，无需服务器。前提是先跑过一次 npm run build。

静态 HTML · 订单管理平台 零依赖零构建，<script data-auto> 一行接入。标注存 localStorage，导出 JSON 交给 AI。 发布态 · 内联标注 + 只读查看 标注内联在 HTML 里，只读模式启动。适合把梳理好的业务逻辑发给他人查阅。 Vue 3 · 需求任务板 验证组件名与组件路径策略，列表增删后标记自动重新锚定。 React 18 · 团队权限管理 从 fiber 上提取组件路径，筛选切换后演示降级与 orphaned 状态。

快捷键：E 选元素 · R 框选区域 · S 标注清单 · H 显隐标记 · Esc 取消
